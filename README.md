## Featured

- **[crave-lab](https://github.com/m-fin/crave-lab)** — Four static web apps. Ride Check compares a rideshare offer (fare, miles, time, and car cost) with your own minimum. Wear Check turns an Open-Meteo forecast into a plain-language outfit. BTC Board shows price, fees, block height, and the halving, with a fullscreen TV mode. Retrograph is a calculator with stat tests, distributions, and graphing.
- **[sonic-rift](https://github.com/m-fin/sonic-rift)** — Source for sonicrift. Python synthesizes the sounds and tracks from scratch. Browser sketches play them with Tone.js. The repo also holds game audio (a title loop, Neon Snake, and the DRIFTHOME cabin) and a Bionic Body piece where each system's readiness score sets how loud that part is.
- **[bionic-body](https://github.com/m-fin/bionic-body)** — A slide deck and a tracker. The deck is the case for living longer by replacing parts. The tracker rates each body system from 0 to 5 on how close a real replacement is, with dated sources.
- **[PostureNet](https://github.com/m-fin/PostureNet)** — HackNC 2019 webcam app. PoseNet (via ml5.js and p5.js) checks head, shoulder, and leg posture and tracks time sitting and standing.

**Stack:** JavaScript, Python, HTML, CSS
